# Pristine Design 组件总览

> 众易搭 T 语言（PSL）配套原生 Web UI 组件库 · v2.0

Pristine Design（众易搭 T 语言 / PSL）是配套的原生 Web UI 组件库，一段简洁文本即可渲染表单、表格、图表与弹窗，无需传统 HTML/CSS 工程。本文档按文档站导航整理全部可用组件与案例，标注 `New` / `HOT` 为新增或热门组件。
