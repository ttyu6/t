# 更新日志

## v2.0 · 2026

**重构**
- 全面移除 jQuery 依赖，改为原生 DOM + 事件委托
- 引入 `BaseUI` 基类与管理器模式，组件统一生命周期
- 样式改用 `data-pd` 属性选择器隔离，避免与业务 CSS 冲突

**新增**
- `TableUI`：多级表头、行列合并、冻结列、表头滚动高亮、虚拟滚动
- `ChartUI`：Canvas 原生绘制，支持双 Y 轴与古风色板
- `CascaderUI`：逐级异步加载与 code 回填
- `UploadUI`：拖拽、进度、本地缩略图预览
- `DSLParser`：属性简写映射、容错模式、`toJSON` 序列化

**改进**
- 表单校验支持自定义 validator 返回值文案
- 弹窗统一 z-index 栈与焦点锁定
- 表格服务端分页支持自定义数据路径

**修复**
- 修正树形多选补齐父节点 id 的逻辑
- 修正弹窗内 Canvas 尺寸为 0 导致的空白
- 修正连续 `mount` 同一容器造成的事件重复绑定

## v1.x · 2025

- v1.6 新增 Carousel、Modal
- v1.4 表格支持行内编辑
- v1.2 引入 DSL 解析，替代手写 HTML 模板
- v1.0 首个版本，覆盖表单与基础展示组件

## 升级提示（v1 → v2）

| 变化 | 迁移方式 |
| --- | --- |
| `$(sel)` 全局函数移除 | 改用 `Pristine.util.$` |
| 组件类名变更 | `Table` → `TableUI`，其余同理 |
| `render()` 返回值改为直接操作 `this.el` | 无需返回 HTML 字符串 |
| 样式类名 `pd-*` 前缀保留 | 无需改动 |
| 事件回调签名 | `(val)` → `(val, ctx)`，ctx 提供组件引用 |
