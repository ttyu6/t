Pristine Design 是配套众易搭 T 语言（PSL）的原生 Web UI 组件库，一段简洁文本即可渲染表单、表格、图表与弹窗。本仓库整理其文档站导航，包含 UI 组件、工具库与实战案例。

## 在线文档

👉 https://ttyu6.github.io/t/

## 本地预览（Docsify）

```bash
npm i -g docsify-cli
docsify serve docs
```

## 本地预览（MkDocs）

```bash
pip install -r requirements.txt
mkdocs serve
```

## 文档结构

- `docs/README.md` / `docs/index.md`：文档首页
- `docs/_sidebar.md`：侧边栏导航（Docsify）
- `docs/_coverpage.md`：封面（Docsify）
- `docs/ui/`：UI 组件分类页面
- `docs/tools.md`：工具库
- `docs/cases/`：实战案例

## 数据来源

Pristine Design 文档站首页导航（v2.0），更新时间 2026。文档站为前端渲染单页应用，建议在浏览器中直接访问查看组件演示与 PSL 代码示例。
